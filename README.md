# HCI-Project-ReviewLLM

ReviewerLLM is a research project and an AI powered tool that analyzes reviews for you to find insights on a product's strengths, weaknesses, improvement strategies, and more. It saves valuable time by reading reviews and summarizing them for you, and allows you to chat with the AI directly to answer any questions you have about the product or reviews.

[Read more about the tool's effectiveness in the paper](https://github.com/humanSan/ProductReviewerLLM-hci/blob/main/Paper.pdf)
